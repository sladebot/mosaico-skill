# Privacy Policy

Last updated: November 16, 2026

Mosaico Device Helper is a skills-only plugin maintained by Souranil Sen. It provides instructions and reference material for ESP-Mosaico workflows. It does not operate a hosted service, provide an MCP server, create user accounts, or independently collect, transmit, retain, sell, or share personal data.

Prompts, files, and other information supplied while using the plugin are processed by the ChatGPT or Codex product in which the plugin runs and are governed by that product's applicable privacy terms and settings. The plugin instructions discourage exposing device credentials, API keys, or local control services to the public internet.

The plugin may direct users to public third-party documentation, including mosaico.ai, Espressif GitHub repositories, and OpenAI documentation. Those services have their own privacy practices.

Questions about this policy can be submitted through the repository's public support channel: https://github.com/sladebot/mosaico-skill/issues
