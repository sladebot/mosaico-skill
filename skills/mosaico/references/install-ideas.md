# Install and run an IDEA

Use this reference when the user wants to run or install an existing ESP-Mosaico IDEA.

## Modes

- **Vibe Mode** is the maintenance environment used to install, develop, switch, and manage IDEAs.
- **IDEA Run** launches an installed IDEA.

On current official quick-start firmware, with the device off, a long press of POWER enters Vibe Mode and a short press launches an IDEA. Some firmware or custom-IDEA states use the documented alternate entry: hold the top AI button while powering on, then release it when the Mosaico logo appears. Prefer the instructions displayed for the installed firmware version.

## Install by six-digit code

1. Enter Vibe Mode.
2. Configure Wi-Fi in `Settings > Wi-Fi`.
3. Tap `Download`, or swipe left and choose `Add IDEA`.
4. Enter the IDEA's six-digit code, confirm the package, download it, and tap `Run`.

Mosaico-Claw's published code is `100000` according to the official guide. Verify the current listing before relying on any other code.

If a download or installation was interrupted, the device may return to Vibe Mode on a short POWER press. Keep it powered and reinstall the IDEA. To save a locally running custom build without publishing it, use `Vibe Mode > Develop > Save Current Build` when supported.

Community review is required for public publication, not for installing a locally developed application on the user's own device.
